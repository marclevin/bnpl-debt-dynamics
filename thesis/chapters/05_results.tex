\subsection{RQ3: Which Interventions Curb the Increase}
\label{sec:results-rq3}

% BUDGET: 1,000 words. The most novel result in the thesis.
%
% CONTENT REQUIRED:
% - Table, all four levers ranked by effect on BNPL borrowing and on default:
%     bureau visibility            ~1%, essentially none
%     mandatory affordability check  essentially none
%     14-day cool-off              nothing alone; -33% where peer influence is present
%     concurrent-facility cap      -54% to -63%; default returns almost to the no-BNPL level
% - Label the concurrent-facility cap HYPOTHETICAL every time it appears beside the
%   three real instruments.
% - THE ARGUMENT, which is what makes this section worth reading: the damage is not
%   that any single BNPL loan is unaffordable, it is that a household holds several at
%   once. Disclosure only tells the bank something. An affordability test examines one
%   loan in isolation. Neither touches how many facilities a household can hold. Only
%   the cap does. The three instruments regulators are actually proposing are the three
%   that do not work in this model.
% - The bureau-visibility contrast deserves its own paragraph: it is the comparison the
%   whole model was built to make, it holds every uncalibrated parameter fixed across
%   both arms, and it survived a complete rebuild of the two parameters underneath it.
%   The near-null result is a finding, not a failure.
% - The defer-versus-desist test is CUMULATIVE BNPL VOLUME over the full horizon, not
%   the timing of purchases. Unchanged volume with a shifted time distribution means
%   agents defer; lower cumulative volume means they desist. The cool-off works only
%   where peer influence is present because delaying purchases lowers the group's
%   visible usage, which lowers everyone else's appetite --- it acts on the social loop,
%   not on the individual.
% - Figure: rq3_interventions_beta1.png (the beta=0 panel goes to the appendix, with
%   the beta=0 column retained in the body table).
